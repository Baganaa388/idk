# Aktar Marka — онлайн дэлгүүр

QPay төлбөртэй, захиалгын дараалалд суурилсан гишүүнчлэлийн хямдралтай, бүрэн удирдлагын
системтэй e-commerce вэбсайт. Техникийн даалгавар: [`CLAUDE.md`](CLAUDE.md). API гэрээ: [`docs/API.md`](docs/API.md).

## Ажиллуулах

```bash
npm install
npm run seed            # зурагнаас гаргасан 6 бараа, категори (давтан ажиллуулахад аюулгүй)
npm run seed -- --demo  # + туршилтын 12 хэрэглэгч, 23 захиалга (анализ харахад)
npm start               # http://127.0.0.1:3000
npm test                # integration тест (түр DB дээр)
```

| Хуудас | Хаяг |
|---|---|
| Дэлгүүр | `/` |
| Админ | `/admin` — анх `admin` / `12345678` (Тохиргоо хэсгээс солино; мартвал `npm run admin -- <шинэ-нууц-үг>`) |

Node.js ≥ 22.13 (built-in `node:sqlite`). Өгөгдөл `data/shop.db`, байршуулсан зураг `data/uploads/`.

## Орчны хувьсагч

| Хувьсагч | Тайлбар |
|---|---|
| `PORT`, `HOST` | Анхдагч `3000`, `127.0.0.1` |
| `PUBLIC_URL` | Гаднаас хандах хаяг (жишээ `https://aktarmarka.mn`) — QPay callback URL-д ашиглана |
| `QPAY_USERNAME`, `QPAY_PASSWORD`, `QPAY_INVOICE_CODE` | QPay мерчант мэдээлэл. **Тохируулаагүй бол mock горим** |
| `QPAY_BASE_URL` | Анхдагч `https://merchant.qpay.mn` (sandbox: `https://merchant-sandbox.qpay.mn`) |
| `QPAY_MOCK=1` | Мерчант мэдээлэлтэй байсан ч туршилтын горимд ажиллуулах |
| `SMS_WEBHOOK_URL`, `EMAIL_WEBHOOK_URL`, `NOTIFY_TOKEN` | OTP илгээх gateway (`POST {to, text}` / `{to, subject, text}`). Тохируулаагүй бол код серверийн консолд хэвлэгдэнэ |
| `OTP_DEV_EXPOSE=1` | Зөвхөн хөгжүүлэлтэд: OTP кодыг API хариунд буцаана |
| `ADMIN_PASSWORD` | Анхны админ үүсэх үеийн нууц үг |
| `DB_PATH`, `UPLOAD_DIR`, `CALLBACK_SECRET` | Нэмэлт тохиргоо |

## Боломжууд

**Дэлгүүр** — бүртгэлгүйгээр каталог, категори/дэд категори, брэнд, үнээр шүүх, хайлт, олон зурагтай
дэлгэрэнгүй. Сагслах/захиалахад нэвтрэлт шаардана: и-мэйл эсвэл утас + нууц үг, эсвэл OTP код.
Сагс, захиалга, QPay QR + банк/зээлийн апп руу шууд шилжих холбоос, төлбөрийн төлөв автоматаар шинэчлэгдэнэ.
Миний захиалга, гишүүнчлэлийн шат, профайл.

**Гишүүнчлэлийн хямдрал** — төлөгдсөн (цуцлагдаагүй) захиалгын тоо + 1 = дараагийн захиалгын дугаар:
1-р 0%, 2-р 10%, 3-р ба цаашид 20%. Шатыг админ Тохиргооноос засна (жишээ нь 5-р захиалгаас 30% гэж нэмж болно) —
хамгийн сүүлийн шат цаашдын бүх захиалгад үйлчилнэ. Хямдрал захиалга үүсэх мөчид тогтож хадгалагдана.

**Төлбөр (QPay v2)** — `auth/token` → `invoice` (QR, `urls[]` deeplink) → `payment/check`.
Төлөв гурван замаар шинэчлэгдэнэ: QPay callback (серверээс дахин шалгана), төлбөрийн хуудасны 4 секундын polling,
серверийн минут тутмын шалгалт. Нэхэмжлэхийн хугацаа (анхдагч 30 мин) дуусахад захиалга цуцлагдаж, үлдэгдэл буцна.
Цуцлагдсаны дараа төлбөр орж ирвэл "буцаалт шаардлагатай" гэж тэмдэглэнэ.

**Агуулах** — захиалга үүсэхэд үлдэгдэл нөөцлөгдөж, цуцлахад буцна; орлого/зарлага/тооллого;
барааны хөдөлгөөн бүр түүхтэй; доод хэмжээнээс бага үед анхааруулга.

**Админ** — хяналтын самбар, захиалга (хүлээгдэж буй → бэлтгэгдэж буй → илгээгдсэн → хүргэгдсэн, QPay синк, CSV),
бараа ба зураг, категори, агуулах, CSV/Excel bulk импорт (preview → commit), хэрэглэгч ба хямдралын шат,
анализ (өдөр/долоо хоног/сар борлуулалт, шилдэг бараа, орлогын график, retention), тохиргоо.

## Бүтэц

```
server.js              Express сервер, аюулгүй байдлын толгой, SPA fallback, төлбөрийн шалгалтын давталт
src/db.js              SQLite схем, тохиргооны анхдагч утга
src/shop.js            Бараа, агуулах, сагс, хямдрал, захиалга, төлбөрийн синк
src/qpay.js            QPay v2 клиент + mock горим
src/auth.js            scrypt нууц үг, session, rate-limit, OTP
src/notify.js          OTP илгээх суваг (SMS / и-мэйл webhook)
src/importer.js        CSV/XLSX импорт
src/analytics.js       Тайлан, retention
src/routes/            account (бүртгэл), store (каталог, сагс, захиалга, төлбөр), admin
public/                Дэлгүүр (index.html, js/store), админ SPA (admin/, js/admin)
scripts/               seed, зураг боловсруулах, CSV экспорт, админ нууц үг
test/                  Integration тест
```

## Production-д шилжүүлэхэд

1. QPay-ээс мерчант эрх авч `QPAY_*`, `PUBLIC_URL` тохируулна (HTTPS заавал — callback).
2. SMS/и-мэйл gateway-г `SMS_WEBHOOK_URL`/`EMAIL_WEBHOOK_URL`-аар холбоно.
3. nginx зэрэг reverse proxy-гийн ард `HOST=127.0.0.1` ажиллуулж, `data/` хавтсыг тогтмол нөөцөлнө.
4. Админы нууц үгийг солино.
