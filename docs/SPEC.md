# E-commerce вебсайт хөгжүүлэлтийн бүрэн техникийн даалгавар

## Ерөнхий тодорхойлолт
Монголд ажиллах, төлбөрийн интеграцтай, гишүүнчлэлийн хямдралтай, бүрэн удирдах боломжтой admin системтэй, dynamic (өгөгдөл дээр суурилсан) e-commerce вебсайт хөгжүүлэх.

UI/UX загвар: https://www.hitech.mn/-тэй ижил байдал, минимал, цэвэрхэн загвар. Emoji болон "AI-ish" харагдах элемент (жишээ нь чатбот bubble, gradient шошго, "Powered by AI" гэх мэт) огт ашиглахгүй.

## 1. Хэрэглэгчийн тал (Storefront)
### 1.1 Бүртгэл ба нэвтрэлт
- Хэрэглэгч бүртгэлгүйгээр бүх барааг үзэх, каталог, дэлгэрэнгүй мэдээлэл харах боломжтой.
- Захиалга өгөх/сагслах үед заавал нэвтрэх/бүртгүүлэх шаардлагатай.
- Бүртгэл: и-мэйл эсвэл утасны дугаараар, нууц үг эсвэл OTP-ээр баталгаажуулах.

### 1.2 Бүтээгдэхүүний каталог
- Категори, дэд категориор шүүх
- Үнэ, тоо хэмжээ (үлдэгдэл), тайлбар, олон зураг харуулах
- Сагслах (cart) → тоо ширхэг өөрчлөх, устгах

### 1.3 Гишүүнчлэлийн үнийн шат (Loyalty tier)
Худалдан авалтын дараалалд тулгуурласан автомат хямдрал:

| Захиалгын дараалал | Хямдрал |
|---|---|
| 1-р худалдан авалт | Үндсэн үнэ (0%) |
| 2-р худалдан авалт | 10% хямдрал |
| 3-р ба цаашид | 20% хямдрал |

Тодруулах шаардлагатай: 3-аас хойшхи бүх захиалгад 20% байнга үйлчлэх үү, эсвэл дараа нь дахин өсөх шат байх уу (жишээ: 5-р захиалгаас 30%)?
> Хэрэгжүүлэлт: анхдагчаар 3-аас хойш 20% байнга; админ Тохиргооноос нэмэлт шат (жишээ 5-р захиалгаас 30%) нэмж болно.

### 1.4 Төлбөрийн систем
- QPay (мерчант интеграц) — QR уншуулж төлөх
- QPay-ээр дамжуулан дараах аппуудаар шууд төлөх сонголтууд:
  - Зээлийн апп (жишээ: Pocket, ХаанБанк зэрэг лизинг/зээлийн үйлчилгээ)
  - Интернет банк аппууд (Хаан, Голомт, ТДБ, Богд, Хас гэх мэт — QPay холбогдсон бүх банк)
- Захиалга өгөгдсөний дараа төлбөрийн төлөв (хүлээгдэж буй / төлөгдсөн / цуцлагдсан) автоматаар шинэчлэгдэнэ.

## 2. Admin панел
### 2.1 Бүтэц
Лавлагаа болгож өгсөн laundry web admin dashboard-ын бүтцийг ашиглана (sidebar navigation, dashboard cards, table-based CRUD layout).

### 2.2 Барааны удирдлага
- Бараа нэмэх/засах/устгах, категори удирдах
- Агуулахын систем: үлдэгдэл (stock), нөөц дуусахад анхааруулга, барааны хөдөлгөөний түүх
- Bulk импорт (Excel/CSV-ээр олноор бараа оруулах боломж)

### 2.3 Захиалгын удирдлага
- Захиалгын жагсаалт, төлөв өөрчлөх (хүлээгдэж буй → бэлтгэгдэж буй → илгээгдсэн → хүргэгдсэн)
- Төлбөрийн төлөв QPay-тай синк хийгдэнэ

### 2.4 Хэрэглэгчийн удирдлага
- Хэрэглэгчийн жагсаалт, худалдан авалтын түүх, тухайн хэрэглэгчийн одоогийн хямдралын шат (1/2/3 дахь захиалга)

### 2.5 Дата анализ (Analytics)
- Борлуулалтын тайлан (өдөр/долоо хоног/сар)
- Хамгийн их зарагдсан бараа
- Орлогын график
- Хэрэглэгчийн эргэн худалдан авалтын хувь (retention)

## 3. Барааны мэдээлэл зурагнаас цуглуулах (Data extraction)
- "info" гэсэн эх сурвалж зурагнуудаас барааны мэдээллийг (нэр, үнэ, тайлбар, тоо ширхэг гэх мэт) унших
- Зургийг цэвэрлэх: шаардлагагүй хэсгийг crop хийх, зөвхөн бүтээгдэхүүний мэдээлэл үлдээх
- Уншсан өгөгдлийг бүтэцтэй (json/хүснэгт) хэлбэрт оруулаад админ системд импортлоход бэлэн болгох
